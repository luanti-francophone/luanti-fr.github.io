# Luanti FR

This repository was the **luanti.fr** website, based on an older version of the official Luanti website.

The project has since evolved: the official website now uses Eleventy and supports multiple languages natively, including French.

👉 [Official French version](https://luanti.org/fr)

---

The Luanti website has been redesigned to:

- adopt a more modern architecture (Eleventy)
- centralise all languages
- improve maintenance and community contribution

The French version is now maintained directly within the main project, via a collaborative translation system.

👉 Translations via [Weblate](https://hosted.weblate.org/projects/minetest/website/)
